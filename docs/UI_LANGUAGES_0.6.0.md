# 0.6.0 界面与常用语言 · 2026-09-26

## 交互

- 首页两个标签“普通翻译 / 连续听译”，支持点击和左右滑动。普通页提供文字、单次说话、图片取词与译文；连续页提供收音和逐段记录。
- 切页停止当前收音和未完成处理；已完成记录保留。连续听译不改写普通页输入文字。两页共用输入语言与目标选择，改选语言会使普通页旧译文失效。
- 顶部“设置”代替“离线就绪”。翻译模型、语音识别模型和离线音色仅在设置中选择。
- 常用语言默认中文、英语、西班牙语、意大利语，至少两种，保存到手机。设置中加入语言不会自动将其选为翻译目标。移除语言会清理已选输入/目标；若目标被全部移除，回退到仍可见的一个语言。
- 首页自动检测仍可识别目录内未加入常用列表的输入语言；“常用”只过滤手动选择列表，并不禁止识别其他语言。

## 语言范围

目录共 12 种：中文、英语、西班牙语、意大利语、法语、德语、葡萄牙语、日语、韩语、俄语、泰语、越南语。语言名称集中维护，供翻译提示、Qwen ASR 提示、Whisper 代码、自动检测、TTS 区域设置和试听使用。

本轮核对的官方来源：

- [HY-MT2 1.8B 支持语言表](https://huggingface.co/tencent/Hy-MT2-1.8B#supported-languages)：以上语言均在列。
- [Qwen3-ASR 语言表](https://github.com/QwenLM/Qwen3-ASR#released-models-description-and-download)：以上语言均在列。
- [Whisper 语言代码](https://github.com/openai/whisper/blob/main/whisper/tokenizer.py)：以上语言均在列。
- [Qwen3.5 4B 官方说明](https://huggingface.co/Qwen/Qwen3.5-4B)：宣称覆盖 201 种语言和方言；并非本项目量化后的逐语言质量保证。

无需额外模型文件，沿用七个已内置权重。扩展了应用语言映射与提示，不代表新增八语已经通过手机准确率测试。已有四语历史冒烟也不能代替 0.6.0 验收。

朗读能力单独按本机离线音色判断；缺少声音不影响文字翻译。OCR 仍只有拉丁字母模型，未新增中日韩、泰文或西里尔文字图片识别。

## 验收清单

代码测试检查语言代码/名称映射、偏好迁移、移除隐藏语言后的选择有效性、至少两语约束、加入常用不自动增加目标、编辑普通文字保留听译记录。安装包检查与手机实测分开记录。

待真机：左右滑动及标签点击、录音中切页、进入设置返回、重启后常用语言保留、连续记录和普通草稿互不覆盖、大字体与键盘遮挡、全部新增语言的两套翻译/ASR 测试和离线音色试听。

连续听译仍是按停顿分段，有模型处理延迟；本轮没有实现逐字流式识别或替换系统 TTS。
